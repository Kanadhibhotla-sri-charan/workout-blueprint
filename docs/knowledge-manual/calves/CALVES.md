# Calves and Lower Leg — Draft Knowledge Module

**Status:** Draft  
**Purpose:** Define the first lower-leg records in the canonical Blueprint format. These records are a starting dataset and must pass the review gate in [FOUNDATION.md](../FOUNDATION.md) before the status is changed to Reviewed.

## Region map

The lower leg is organized around knee position, because knee angle decides which calf muscle does most of the work, and around the front of the shin, which nothing else in a routine trains.

- **Straight-knee plantarflexion:** the gastrocnemius crosses the knee, so it contributes most when the knee is straight.
- **Bent-knee plantarflexion:** with the knee bent, the soleus does more of the work.
- **Unilateral plantarflexion:** one leg at a time, useful when loading options are limited.
- **Dorsiflexion:** lifting the foot upward; the tibialis anterior, which no common lift trains directly.

## Draft records

### Standing Calf Raise

- **Why this exists:** The straight-knee position lets the gastrocnemius contribute, which a seated raise limits.
- **Primary targets:** Gastrocnemius; soleus contributes.
- **Movement:** Ankle plantarflexion with the knee straight.
- **Coverage:** Isolation, low skill demand, low-to-moderate setup.
- **Best used when:** A user wants calf work in the position where the gastrocnemius is most involved. A machine gives a fixed path and lets a user go close to failure alone; holding dumbbells while standing on a block or plate is the free-weight equivalent and needs no machine at all.
- **Less suitable when:** Balance or the shoulder pads are the limiting factor rather than the calves.
- **Complements:** A bent-knee raise, which covers the soleus.
- **Overlaps:** Leg-press and single-leg calf raises.
- **Status:** Draft.

### Seated Calf Raise

- **Why this exists:** The bent knee reduces the gastrocnemius contribution, so the soleus carries more of the work.
- **Primary targets:** Soleus; gastrocnemius contributes.
- **Movement:** Ankle plantarflexion with the knee bent.
- **Coverage:** Isolation, stable, low skill demand, low fatigue cost.
- **Best used when:** A routine already has standing calf work and the soleus is not being trained separately.
- **Less suitable when:** No seated machine is available.
- **Complements:** A straight-knee raise.
- **Overlaps:** Other bent-knee plantarflexion variations.
- **Status:** Draft.

### Leg-Press Calf Raise

- **Why this exists:** Uses a machine most gyms already have, so calf work does not depend on a dedicated calf station.
- **Primary targets:** Gastrocnemius and soleus, depending on how straight the knee is kept.
- **Movement:** Ankle plantarflexion.
- **Coverage:** Isolation, stable, low setup when already using the leg press.
- **Best used when:** No calf machine is free, or a user wants to add calves to the end of a leg-press set.
- **Less suitable when:** The knee angle drifts, which makes the emphasis inconsistent between sessions.
- **Complements:** A raise done in the other knee position.
- **Overlaps:** Standing and seated calf raises.
- **Status:** Draft.

### Single-Leg Calf Raise

- **Why this exists:** Needs almost no equipment, since bodyweight on one leg is often load enough, and exposes side-to-side differences.
- **Primary targets:** Gastrocnemius; soleus contributes.
- **Movement:** Unilateral ankle plantarflexion.
- **Coverage:** Unilateral, low equipment, low setup.
- **Best used when:** Training at home, or when available loads are too light for bilateral work.
- **Less suitable when:** Balance limits the set, or session time is short.
- **Complements:** A seated raise for the soleus.
- **Overlaps:** Other plantarflexion variations.
- **Status:** Draft.

### Tibialis Raise

- **Why this exists:** Directly trains the front of the shin, which no common lower-body lift loads.
- **Primary targets:** Tibialis anterior.
- **Movement:** Ankle dorsiflexion.
- **Coverage:** Isolation, low fatigue cost, low setup with a wall, band, or dedicated device.
- **Best used when:** A user wants balanced lower-leg development, or spends a lot of time running or walking.
- **Less suitable when:** Larger movements in the session have not been covered yet.
- **Complements:** Plantarflexion work.
- **Overlaps:** Banded and machine dorsiflexion variations.
- **Status:** Draft.

## Review checklist

Before changing a record to Reviewed:

- Confirm the record answers "when would I choose this over an alternative?"
- Add equipment, setup, fatigue, and relationship fields in the final data format.
- Check terminology against the writing standard.
- Add evidence notes for claims that require them.
